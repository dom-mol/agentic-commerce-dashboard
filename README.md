# Allow or block shopping agents?

Interactive dashboard for comparing incremental profit from shopping-agent access across initial retailer market shares.

Open `index.html` in a browser. No installation or server is required.

Includes adjustable model parameters, participation thresholds, scenario comparisons, and CSV export. The baseline threshold is 18.75%; the Case 2 example has a 37.5% threshold.

Run model checks with `node verify.cjs`.
