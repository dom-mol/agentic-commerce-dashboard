# Allow or block shopping agents?

Interactive dashboard for comparing incremental profit from shopping-agent access across initial retailer market shares.

Open `index.html` in a browser. No installation or server is required.

Includes adjustable model parameters, participation thresholds, scenario comparisons, and CSV export. Cases 1 and 2 both use $190,000 in annual fixed costs and differ only in defection under blocking (20% versus 60%). Case 1 has an 18.75% participation threshold; Case 2 favors access at every feasible market share.

Run model checks with `node verify.cjs`.
